# Prime Defense Members App - Single Service

This is the path-of-least-resistance version.

Render settings:
- Root Directory: backend
- Build Command: npm install
- Start Command: node server.js

Environment variables:
- STRIPE_SECRET_KEY
- STRIPE_WEBHOOK_SECRET
- JWT_SECRET
- FRONTEND_URL=https://app.primedefensetraining.com

This version does NOT need a frontend build, Vite, or a separate static site.
